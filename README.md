# ENGR4399-ESP32-Wifi-Assignment
Wokwi simulation and physical esp32 connecting to Adafruit dashboard to display sensor data. Motion detection from the pir sensor, temperature and humidity from the DHT11, and an led switch. 

https://wokwi.com/projects/477731720612761601

SAR 3 Asks us to connect the ESP32 to wifi and establish connection with a web service or API. I chose to use Adafruit and to display sensor data. Both physical and wokwi simulation work with the dashboard. If you open the .ino file please make sure the wifi name and password match what you have available. 
In the simulation, the esp32 connects to the Wokwi-GUEST wifi while the physical one connects to either a hotspot called Sai or Linksley. Either way they connect to Adafruit using the provided api key to exchange data.
